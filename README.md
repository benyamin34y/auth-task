# BizMart Pro - Professional E-commerce WordPress Theme

BizMart Pro is a modern, professional WordPress theme designed specifically for e-commerce websites. Inspired by WoodMart, this theme is built to work seamlessly with Elementor and WooCommerce, making it perfect for 99% of businesses looking to create a stunning online store.

## 📋 Requirements

- WordPress 5.0 or higher
- PHP 7.4 or higher
- WooCommerce 4.0 or higher (for e-commerce features)
- Elementor (recommended for best experience)

## 🔧 Installation

1. **Download** the theme files
2. **Upload** to your WordPress site via `Appearance > Themes > Add New > Upload Theme`
3. **Activate** the theme
4. **Install** required plugins (WooCommerce, Elementor)
5. **Import** demo content (optional)
6. **Customize** via `Appearance > Customize`
